# Getting help

| I want to... | Go to |
| --- | --- |
| Learn how to use slopguard | [Getting started](docs/getting-started.md), [FAQ and troubleshooting](docs/faq.md) |
| Look up an option or a rule | [Configuration](docs/configuration.md), [commands](docs/cli.md), [rules](docs/rules.md) |
| Ask a question or share an idea | [GitHub Discussions](https://github.com/patsypppe/slopguard/discussions) if enabled, otherwise an [issue](https://github.com/patsypppe/slopguard/issues/new/choose) labelled "question" |
| Report a false positive or a missed problem | [Open an issue](https://github.com/patsypppe/slopguard/issues/new/choose) and pick the matching form |
| Report a bug | [Open an issue](https://github.com/patsypppe/slopguard/issues/new/choose) |
| Report a security problem in slopguard | [SECURITY.md](SECURITY.md), privately |

Please include the output of `slopguard --version`, the command you ran, and the smallest code that shows
the problem. No example, no way to fix it: that is the most useful thing you can send.

Maintenance is done by volunteers, so replies are not instant.
